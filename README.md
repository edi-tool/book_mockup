# cover_image
印刷用カバーPDFから判型・背幅を反映した書籍モックアップPNGを生成するブラウザツール。
公開予定 https://edi-tool.github.io/cover_image/ （未実装）
PDF選択 → 判型・背幅 → 仕上がり範囲調整 → 角度 → PNG保存。生成AI・外部API・サーバー処理なし。
